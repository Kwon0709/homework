# 피보나치 복잡도 분석 보고서

## 1. 개요

본 보고서는 재귀적 방법으로 구현한 피보나치 수열과 유클리드 호제법(GCD)의 시간복잡도를 실험적으로 검증한다.  
n을 5부터 45까지 순서대로 증가시키며 `F(n)`과 `GCD(F(n), F(n-1))`을 계산하고,  
`time.h`의 `clock()` 함수를 이용해 각 n에 대한 실행 시간을 측정하였다.

---

## 2. 구현 코드 (핵심 부분)

### 재귀 피보나치

```c
my_fibonacci fibonacci(my_fibonacci n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

### GCD (유클리드 호제법)

```c
my_fibonacci find_Gcd(my_fibonacci a, my_fibonacci b) {
    while (b != 0) {
        my_fibonacci tmp = b;
        b = a % b;
        a = tmp;
    }
    return a;
}
```

### 실행 시간 측정 (main.c 핵심)

```c
#include <time.h>

for (my_fibonacci n = 5; n <= 45; n++) {
    clock_t start = clock();
    my_fibonacci fn    = fibonacci(n);
    my_fibonacci fn_1  = fibonacci(n - 1);
    my_fibonacci result = find_Gcd(fn, fn_1);
    clock_t end = clock();

    double elapsed = (double)(end - start) / CLOCKS_PER_SEC * 1000;
    printf("%llu\t%llu\t%llu\t%.3f ms\n", n, fn, result, elapsed);
}
```

## 4. Big-O 분석

### 4-1. 재귀 피보나치: O(2ⁿ)

재귀 피보나치는 `F(n) = F(n-1) + F(n-2)` 형태로, 각 호출이 두 번의 재귀 호출을 발생시킨다.  
이를 점화식으로 표현하면 다음과 같다.

```
T(n) = T(n-1) + T(n-2) + O(1)
     ≈ 2 * T(n-1)
     → T(n) = O(2ⁿ)
```

더 정확하게는 황금비 φ ≈ 1.618을 이용해 **O(φⁿ)** 으로 표현할 수 있다.

**실험적 검증:**

n이 1 증가할 때마다 실행 시간이 약 1.6배씩 증가함을 관찰할 수 있다.

| 구간       | 실행 시간 비율 |
|------------|--------------|
| n=40 → 41 | 2511 / 1542 ≈ **1.63배** |
| n=41 → 42 | 4057 / 2511 ≈ **1.62배** |
| n=42 → 43 | 6535 / 4057 ≈ **1.61배** |
| n=43 → 44 | 10540 / 6535 ≈ **1.61배** |
| n=44 → 45 | 17053 / 10540 ≈ **1.62배** |

n이 1 증가할 때마다 실행 시간이 **황금비(φ ≈ 1.618)배**씩 증가하므로,  
재귀 피보나치의 시간복잡도 **O(φⁿ) ≈ O(2ⁿ)** 이 실험적으로 검증된다.

---

### 4-2. GCD (유클리드 호제법): O(log n)

유클리드 호제법은 매 단계마다 나머지 연산을 수행하며, 피보나치 수가 입력일 때 나눗셈 횟수가 최대가 된다(라메의 정리).  
이 경우에도 나눗셈 횟수는 입력 자릿수에 비례하므로 시간복잡도는 다음과 같다.

```
T(n) = O(log(min(a, b)))
```

**실험적 검증:**

F(n)의 값이 수억 단위로 커지더라도 GCD 실행 시간은 측정 불가 수준(0ms)으로 일정하게 유지되었다.  
이는 입력값이 지수적으로 증가해도 연산 횟수는 로그적으로만 증가함을 의미하며,  
GCD의 시간복잡도 **O(log n)** 이 실험적으로 검증된다.
