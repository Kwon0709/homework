# 피보나치 수열 GCD 프로파일링 예상 보고서

### 피보나치 수열
피보나치 수열은 다음과 같이 정의된다.
```
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)  (n >= 2)
```

| n | F(n) |
|---|------|
| 5 | 5 |
| 6 | 8 |
| 7 | 13 |
| 8 | 21 |
| 9 | 34 |
| 10 | 55 |

### GCD(F(n), F(n-1)) 예상 결과
인접한 피보나치 수는 서로소(최대공약수가 1)이므로 GCD(F(n), F(n-1)) = 1 이 예상된다.

---

## 시간복잡도 예상

### GCD 시간복잡도
앞선 1) 과제에서 분석한 바와 같이 유클리드 호제법의 시간복잡도는 **O(log n)** 이다.

### 프로파일링 예상
n이 증가할수록 피보나치 수 F(n)이 커지므로 GCD 연산의 입력값도 커진다.
따라서 n이 증가할수록 GCD 연산 시간도 **로그 비례**로 증가할 것으로 예상된다.

```
n 증가 → F(n) 증가 → GCD 입력값 증가 → GCD 연산 시간 O(log F(n)) 증가
```

### CPU 사용량 예상
- n이 커질수록 피보나치 수가 커지므로 GCD 연산량도 증가
- CPU 사용량은 **완만하게 증가**할 것으로 예상 (O(log n) 특성)

### 메모리 사용량 예상
- 변수 몇 개만 사용하므로 메모리 사용량은 **거의 일정**할 것으로 예상
- n이 증가해도 추가적인 메모리 할당이 없음

---

| GCD(F(n), F(n-1)) | 항상 1 |

| 메모리 사용량 | 거의 일정 |
