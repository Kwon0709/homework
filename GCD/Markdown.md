# GCD알고리즘의 시간복잡도 Big-O계산 보고서
## 알고리즘 개요

이 프로그램에서 GCD(최대공약수)를 구하기 위해 구현한 알고리즘은 **유클리드 호제법**이다.
```c
my_math find_Gcd(my_math a, my_math b) {
	while ( b!= 0) {
		int tmp = b;
		b = a % b;
		a = tmp;
	}
	return a;
}
```
---
## 시간복잡도 구하기

### 시간복잡도 구하는 법
시간복잡도는 명령문의 실행 빈도수를 계산하여 추정한다

### 핵심 연산
유클리드 호제법의 핵심 연산은 `a % b` (나머지 연산)이며, while 루프가 반복될 때마다 b의 값이 감소한다.

### 반복횟수분석
예시) a=18과 b=24를 입력 받음
---
| 단계 | a | b |
|------|---|---|
| 초기 | 18 | 24 |
| 1회 | 24 | 18 |
| 2회 | 18 | 6 |
| 3회 | 6 | 0 |

-> **종료:find_Gcd=6**

---
위 예시값(18,24)는 3번 반복 후 끝이난다

위 예시를 토대로 시간복잡도를 계산해보자면
```
(b > a 인 경우)
a=18 b=24
```c
while ( b!= 0) {
	int tmp = b;
	b = a % b;
	a = tmp;
}
return a;

18 % 24 = 18 a=24,b=18
24 % 18 = 6 a=18, b=6
18 % 6 = 0 a=6, b=0 while(b!=0) 조건에 걸려서 while문 탈출
return a; 
```
```
(b<a인 경우)
a=24 b=18
```c
while ( b!= 0) {
	int tmp = b;
	b = a % b;
	a = tmp;
}
return a;
24 % 18 = 6 a=18 b=6
18%6=0 a=6 b=0 while(b!=0) 조건에 걸려서 while문 탈출
return a;
```
여기서 실행빈도를 계산해보자면 입력 받은 수 중 작은 수를 n이라 잡았을때
```

**b>a인 경우**n*(1/2)^(k-1)=1

**b<a인 경우**n*(1/2)^k=1

매 연산마다 b가 절반 이하로 줄어들기 때문에 n=1이 아닌 n*(1/2)^(k-1)=1, n*(1/2)^k=1이 됨
```


시간복잡도는 최악의 경우를 생각한다

이때 b>a인 경우는 첫 번째 연산에서 자리바꿈만 일어나 실질적인 감소가 없다

따라서 이 알고리즘에 시간복잡도는 최악의 경우인 **b>a일때 n*(1/2)^(k-1)=1**이된다.
---
## Big-O 계산 및 표기

### Big-O 계산법
최악의 경우인 b > a 일 때의 식을 풀어보면

n * (1/2)^(k-1) = 1
(1/2)^(k-1) = 1/n
2^(k-1) = n
k-1 = log₂n
k = log₂n + 1

따라서 실행 빈도수는 **log₂n + 1** 이다.

### Big-O 표기법
Big-O 표기법은 최고차항만 남기고 상수를 무시한다.

log₂n + 1 에서
- 상수 +1 제거
- 밑 2 제거 (로그 밑 변환 공식에 의해 밑은 상수로 취급되어 무시)

∴ **O(log n)**
