# GCD 알고리즘의 시간복잡도 및 Big-O 분석 보고서

## 1. 알고리즘 개요

이 프로그램에서 GCD(최대공약수)를 구하기 위해 구현한 알고리즘은 **유클리드 호제법**이다.

```c
my_math find_Gcd(my_math a, my_math b) {
    while (b != 0) {
        my_math tmp = b;
        b = a % b;
        a = tmp;
    }
    return a;
}
```

이 알고리즘은 두 정수 a와 b에 대해
b가 0이 될 때까지 a를 b로 나눈 나머지를 반복적으로 구하여 최대공약수를 계산한다.

---

## 2. 시간복잡도 분석

### 2.1 시간복잡도 정의

시간복잡도는 입력 크기에 따라 알고리즘이 수행되는 연산 횟수를 기반으로 추정한다.

---

### 2.2 핵심 연산

유클리드 호제법의 핵심 연산은 `a % b` (나머지 연산)이며,
while 루프가 반복될 때마다 b의 값은 점점 감소한다.

---

### 2.3 반복 횟수 분석

예시) a = 18, b = 24

| 단계 | a  | b  |
| -- | -- | -- |
| 초기 | 18 | 24 |
| 1회 | 24 | 18 |
| 2회 | 18 | 6  |
| 3회 | 6  | 0  |

→ 종료: GCD = 6

이처럼 반복이 진행될수록 b의 값은 빠르게 감소하며, 알고리즘은 짧은 시간 내에 종료된다.

---

### 2.4 최악의 경우 분석

유클리드 호제법에서 반복 횟수는 입력값에 따라 달라지며,
**피보나치 수열을 이루는 두 수를 입력으로 사용할 때 최대**가 된다.

이 경우 나머지 값이 가장 천천히 감소하게 되며, 반복 횟수가 최대로 증가한다.

각 단계에서 나머지 연산에 의해 값의 크기는
**최소 절반 이하로 감소한다고 볼 수 있다.**

따라서 반복 횟수는 다음과 같이 계산할 수 있다.

b > a 인 경우
n × (1/2)^(k-1) = 1  →  k = log₂n + 1

b < a 인 경우
n × (1/2)^k = 1      →  k = log₂n

---

## 3. Big-O 계산 및 표기

### 3.1 반복 횟수

위의 분석 결과 반복 횟수는 다음과 같이 표현된다.

* (b > a) : k = log₂n + 1
* (b < a) : k = log₂n

---

### 3.2 Big-O 표기법

Big-O 표기법에서는 최고차항만 남기고 상수는 무시한다.

* log₂n + 1 → 상수 +1 제거
* log₂n → 밑(base)은 상수이므로 제거

따라서 두 경우 모두 동일하게 정리된다.

→ **O(log n)**

---

## 4. 결론

유클리드 호제법의 반복 횟수는 입력값이 클수록 증가하지만,
그 증가 속도는 로그에 비례한다.

특히 피보나치 수열을 이루는 입력에서 최악의 경우가 발생하며,
이때 반복 횟수는 다음과 같이 표현된다.

* b > a : k = log₂n + 1
* b < a : k = log₂n

두 경우 모두 Big-O 표기법에서 상수를 제거하면 동일하게
**O(log n)** 의 시간복잡도를 가진다.
